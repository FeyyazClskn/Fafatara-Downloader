## 🚀 Kurulum

### Hazır sürüm

1. [Releases](https://github.com/FeyyazClskn/Fafatara-Downloader/releases) sayfasına gidin.
2. En son `.zip` dosyasını indirin.
3. ZIP dosyasını çıkartın.
4. `Fafatara-Downloader.exe` dosyasını çalıştırın.

Kurulum gerektirmez.

### Kaynak kodundan çalıştırma

```bash
git clone https://github.com/FeyyazClskn/Fafatara-Downloader.git
cd Fafatara-Downloader
python -m pip install -r requirements.txt
python main.py
```

## 🚀 Installation

### Pre-built version

1. Go to the [Releases](https://github.com/FeyyazClskn/Fafatara-Downloader/releases) page.
2. Download the latest `.zip` file.
3. Extract the ZIP archive.
4. Run `Fafatara-Downloader.exe`.

No installation is required.

### Run from source

```bash
git clone https://github.com/FeyyazClskn/Fafatara-Downloader.git
cd Fafatara-Downloader
python -m pip install -r requirements.txt
python main.py
```
